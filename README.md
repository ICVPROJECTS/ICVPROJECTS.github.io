# ICV IPTV — sitio oficial de prelanzamiento

Sitio estático público de ICV IPTV para GitHub Pages. Presenta la aplicación, sus funciones, los planes previstos, el paso a paso de compra, soporte y documentos legales informativos.

La aplicación no incluye canales, listas ni suscripciones de contenido. El sitio tampoco contiene el código fuente de la aplicación, credenciales, llaves de pago ni datos privados.

URL prevista: <https://icvprojects.github.io>

Contacto: `icvstore01@gmail.com`.

Los cobros reales permanecen deshabilitados. La compra se realizará exclusivamente dentro de la aplicación cuando LG y el procesador aprueben el servicio comercial.
