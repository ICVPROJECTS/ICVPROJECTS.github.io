# ICV IPTV — sitio oficial de pre-lanzamiento

Sitio estático público de ICV IPTV para GitHub Pages. Presenta la aplicación, sus funciones, los planes previstos, soporte, documentos legales informativos y el estado real de preparación para LG Content Store.

La aplicación no incluye canales, listas ni suscripciones de contenido. El sitio tampoco contiene el código fuente de la aplicación, credenciales, llaves de pago ni datos privados.
