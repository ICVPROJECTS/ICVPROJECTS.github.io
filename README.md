# ICV IPTV — sitio oficial

Sitio estático público de ICV IPTV para GitHub Pages. Presenta la aplicación, sus funciones, los planes, el paso a paso de adquisición, soporte y documentos legales.

La aplicación no incluye canales, listas ni suscripciones de contenido. El sitio tampoco contiene el código fuente de la aplicación, credenciales, llaves de pago ni datos privados.

URL prevista: <https://icvprojects.github.io>

Contacto: `icvstore01@gmail.com`.

Los planes se consultan y gestionan exclusivamente desde la sección Licencia de la aplicación. Esta web no recopila datos financieros ni incorpora un checkout.
